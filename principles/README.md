# Principles

One document per enforceable rule. A principle says when it applies, what must hold and by when,
what evidence counts, which verifiers must have spoken, which capabilities it withdraws, and what
happens on failure.

Grouped by the four layers of design §26:

| Directory | Question |
|---|---|
| `development/` | what should exist, and how it should be produced |
| `verification/` | how do we know it works |
| `operations/` | how is it run and recovered |
| `governance/` | under what controls may it operate |

Directories are for humans; the `id` inside each document is what resolution uses.
