# Protocol declarations

One document per protocol major version: the vocabulary a profile is allowed to use — capabilities,
evidence kinds, verifiers, artifact kinds, observable fact families and ordered scales.

`aep/1` is the base. `adp/1` and `aop/1` extend it rather than restating it; extension is additive,
because a principle written against the base must keep working.

Referenced as `aep/1`. Validated by `RawProtocol` → `Protocol`.
