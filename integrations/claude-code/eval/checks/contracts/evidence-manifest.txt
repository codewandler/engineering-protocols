# The recordings the live-only rows are asserted against.
#
# Some acceptance rows — S1, S2, V1, V2, R1, L1, L2, L3 — are claims about a run that reaches the
# Claude API. A hermetic check cannot make that run, and `A vacuous check is a failed check` forbids
# reporting the row as skipped. So each of them is asserted against a **recording**: the run's own
# output, committed verbatim by `task:agent-eval-live-evidence`, which is the same evidence the
# specification's Acceptance Criteria demand ("shown by a recorded run, not argued").
#
# A recording that is missing is a red row, never an absent one. That is the whole design: the live
# rows stay in the table, and the table stays honest between releases.
#
# Paths are relative to `integrations/claude-code/eval/`. Format: <path>\t<what it is>.

evidence/run-1-live.txt	run 1, live and unmutated: the full run-agents.sh output, verbatim
evidence/run-2-decomposer-mutated.txt	run 2, decomposer hard rule 1 deleted: the full output, verbatim
evidence/run-3-plan-reviewer-mutated.txt	run 3, plan-reviewer's "You change nothing" section removed: the full output, verbatim
evidence/offline-fixtures-present.txt	--offline against the committed fixtures: the full output, verbatim
evidence/offline-fixtures-missing.txt	--offline with eval/fixtures/ removed: the full output, verbatim

# Every recording is the run's output verbatim, plus one line the shell adds because a transcript of
# stdout cannot carry an exit code:
#
#   exit: <the run's exit status>
#
# `S2`, `L1`, `L2`, `L3`, `L5` and `L6` all read it. A recording without it is a recording of a run
# whose verdict nobody wrote down, and those rows go red.
#
# Two further lines every *live* recording must carry, so `L8` can be a fact rather than a
# resemblance:
#
#   session: decomposer <session_id>
#   session: plan-reviewer <session_id>
#
# `L8` reads those ids and requires the committed `eval/fixtures/*.jsonl` to carry the same
# `session_id` in their init event. Matching ids is what makes the fixtures *run 1's* transcripts
# rather than transcripts that look like them.
